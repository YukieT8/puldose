💾 Резервная копия

Скачайте JSON на одном устройстве и загрузите на другом — расписание, заметки, ссылки и файлы перенесутся.

☁️ Синхронизация

Как подключить второе устройство:
  1. На первом устройстве (где уже есть данные) создайте токен GitHub: github.com/settings/tokens/new?scopes=gist (галочка gist)
  2. Вставьте токен в поле ниже → «Подключить». Появится код подключения — скопируйте.
  3. На втором устройстве: этот же диалог → вставьте код → «Подключить». Данные придут.
Вставьте этот код в поле «Код подключения» на другом устройстве — данные придут автоматически. Код = токен + ID гиста в base64. Не публикуйте его.
